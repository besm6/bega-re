# Примеры игровых сеансов

```sh
./run-bega.sh < sessions/bega/races.txt
```

Файлы содержат только ввод пользователя, по одному ответу на строку.
Запускалка сама входит в архив ИГРА и запускает БЕГА.
Полный вывод и трассы проверенных сеансов появляются после
`make check-bega` в `build/bega/logs/`.

| Файл | Содержание |
|---|---|
| [help.txt](help.txt) | Общая справка и объяснение приказа КРЕСТИКИ |
| [landing-crash.txt](landing-crash.txt) | Полный полёт без торможения, авария и завершение |
| [landing-english.txt](landing-english.txt) | Английская версия: идеальная посадка с остатком топлива |
| [checkers-white.txt](checkers-white.txt) | Игра белыми, ход `0-2`, ответ компьютера, сдача |
| [checkers-black.txt](checkers-black.txt) | Игра чёрной фишкой, первый ход компьютера, сдача |
| [races.txt](races.txt) | Один полный забег шести лошадей |
| [tictactoe.txt](tictactoe.txt) | Разметка поля для игры вдвоём в автономном режиме терминала |

## Посадка на Луну

`ПОСАДКА` запускает русский вариант, `LANDING` — английский.
Сначала вводится уровень опыта `0–9`; пример выбирает `2`.
На каждом следующем шаге вводится расход топлива: `0` или `8–200`.
По умолчанию шаг составляет десять секунд. Ввод `К` в ответ на запрос
расхода возвращает к приказам игрового блока.

В `landing-crash.txt` первые двенадцать нулей задают свободное падение
на интервалах, начинающихся в 0, 10, …, 110 секунд. Касание происходит
на 114-й секунде со скоростью 5880 фут/с; программа сообщает о кратере
глубиной 1117 футов. Последний, тринадцатый ноль отвечает на вопрос
`ЕЩЕ РАЗ (1) ИЛИ ВСЕ (0) ?`. Затем идут `КОН` и `КОНЕЦ`.
Это пример аварийного завершения, а не мягкой посадки.

`landing-english.txt` доводит полёт до сообщения `PERFECT LANDING`.
При уровне опыта `2` последовательность расхода следующая:

| Время, с | Ввод | Действие |
|---|---|---|
| 0–70 | Семь строк `0` | Свободное падение, шаг 10 секунд |
| 70–71 | `T10` | Перейти на шаг 1 секунда, расход 0 |
| 71–72 | `109` | Расход 109 фунтов/с на одну секунду |
| 72–142 | `T+200`, затем шесть строк `200` | Шаг 10 секунд, максимальное торможение |
| 142–148 | `T6200` | Шаг 6 секунд, расход 200 |
| 148–149 | `T199` | Шаг 1 секунда, расход 99 |
| До касания | `102` | Заключительное торможение |

В командах `T` следующий символ задаёт интервал, а оставшиеся цифры —
расход. Поэтому `T199` означает интервал **1** и расход **99**;
`T+200` означает интервал **10** (`+` имеет код 10 в ГОСТ) и расход **200**.
Вывод сообщает о касании на 149-й секунде, скорости 3 фут/с и остатке
576 фунтов топлива. Напечатанная скорость округлена; оценку
`PERFECT LANDING` выбирает сама игра по неокруглённому значению.
Последний `0` отклоняет повторный полёт, затем `КОН` и `КОНЕЦ`
штатно завершают сеанс.

## Французские шашки

На поле 11 клеток, три белые фишки и одна чёрная. Это вариант игры
«Лиса и гончие». Белые стремятся окружить чёрную, чёрная — попасть
на клетку 0. На вопросы отвечайте `ДА` или `НЕТ`.

Приказ `ШАШКИ` спрашивает, нужны ли правила и хотите ли вы играть белыми.
В белом примере ответы — `НЕТ`, `ДА`, затем допустимый ход `0-2`.
Компьютер отвечает ходом чёрной. В чёрном примере оба ответа — `НЕТ`,
после чего компьютер сразу делает первый ход белыми.
Выбор ответа компьютера зависит от времени запуска.

`СДАЮСЬ` завершает партию поражением пользователя. `НЕТ` на следующий
вопрос отклоняет новую партию. Приказ `КОНЕЦ` внутри шашек возвращает
в игровой блок; затем нужны `КОН` и ещё один `КОНЕЦ` для выхода из ПУЛЬТа.
`ПОЛЕ` перерисовывает доску. Приказы можно сокращать до первой буквы.

## Скачки

После `БЕГА` ответьте `ДА` на вопросы `НАЧИНАТЬ ?` и `НАЧНЕМ ?`.
Далее шесть лошадей проходят трассу автоматически; часть может выбыть.
По окончании на вопрос `ЕЩЕ ПОБЕГАЕМ ?` пример отвечает `НЕТ`.
Порядок финиша и классы лошадей зависят от случайного начального состояния.

## Крестики

`КРЕСТИКИ` рисует сетку из точек для двух людей за автономным терминалом.
Программа не выбирает ходы и не определяет победителя.
В локальном окружении после разметки управление возвращается в ПУЛЬТ;
последний `КОНЕЦ` в примере завершает задание.

Графические игры выводят команды перемещения курсора ANSI.
Просматривайте их в терминале; сохранённый `.out` содержит эти команды
вместе с текстом. Вариант с curses-консолью можно запустить как
`./run-bega.sh -V` в настоящем терминале; автоматические проверки
используют обычный вывод без curses.
