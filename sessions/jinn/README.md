# Сеансы общего запуска

```sh
./run-jinn.sh < sessions/jinn/basic.txt
```

| Файл | Содержание |
|---|---|
| [basic.txt](basic.txt) | Дата 31.12.83 и календарь трёх месяцев через СТАТ |
| [library.txt](library.txt) | ШКОЛА, затем БИБЛ с ЮМОРОМ и первым выпуском РОМАНА |
| [landing.txt](landing.txt) | МОСТ → БЕГА → идеальная английская посадка → МОСТ |
| [kalah.txt](kalah.txt) | МОСТ → БЕГА → КАЛАХ категории У, ходы ДЖИНа `1,6`, возврат и дата |
| [missing.txt](missing.txt) | Отказы ИНФ, ЛОТО и ВРЕ; затем работающая команда даты |
| [routing.txt](routing.txt) | Пять входов ИГР через МОСТ и СТАТ, возвраты из ШКОЛЫ, два показа справки и поля шашек |

Файлы содержат только ввод пользователя. В конце `КОН` завершает задание
со словами `ДО СВИДАНИЯ !`; дополнительный `КОНЕЦ` ПУЛЬТа не нужен.
В `basic.txt` первый `КОН` возвращает из СТАТ в МОСТ, второй завершает
задание. Три последовательных `КОН` после перерисовки в `kalah.txt`
завершают тренировку, возвращают из КАЛАХ в БЕГА, затем из БЕГА в МОСТ.

Чтение романа и игры меняют местные счётчики. `make check-jinn` использует
временную копию и сохраняет постоянные результаты. Происхождение блоков
и ограничения запуска описаны в [JINN.md](../../JINN.md).
